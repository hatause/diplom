# Общая палитра практикума — 15 октября 2026

## Изменения

Цвета конструктора приведены к существующей палитре сайта: кремовые поверхности, коричневые акценты, тёплая тёмная тема. Оформлены все пять вкладок, боковые панели, BIOS, Windows, диагностика, мини-тесты и управление 3D. Цвета материалов физических компонентов сохранены.

Токены перенесены без изменения значений из `globals.css` в общий `public/pc-lab-assets/site-theme.css`. React импортирует их при сборке; оба документа практикума подключают тот же файл. `theme-sync.js` синхронизирует тему с same-origin родителем и читает сохранённое предпочтение в самостоятельном режиме. Токены авторизации для этого не используются.

В верхней панели практикума добавлено переключение общей темы. Кнопка фона внутри 3D остаётся локальным управлением просмотром. Смена общей темы снова синхронизирует сцену. Нехешированные CSS/JS находятся в каталоге с `Cache-Control: no-cache`.

## Проверки в этом проходе

- `npm run build --prefix frontend` — успешно; предупреждение о размере JS-bundle остаётся.
- `npm run lint --prefix frontend` — успешно.
- `scripts/check-pc-hardware.cjs` — 61 проверка прошла: модели, управление, извлечение, установка, отсутствие бесконечного рендера, узкие экраны, fallback без WebGL.
- Дополнительный целевой Playwright-проход — 21 проверка: одинаковые вычисленные цвета трёх документов, светлая/тёмная тема, восстановление после обновления, сохранность разобранной модели, частичной сборки и ответов Windows, локальный фон сцены, ширина 390/320 px, отсутствие ошибок JavaScript.
- Визуально просмотрены светлая сцена GPU, тёмная сцена, BIOS, Windows с ошибкой, мини-тесты и мобильный интерфейс.
