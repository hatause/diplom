# Состояние текущего проекта

Рабочая папка: AItutorJavaServer. Старый GitHub team-ENERGO использовался только для чтения структуры Java/C++ и протокола поиска кабинета.

| Часть | Реализация |
|---|---|
| frontend | React 19, TypeScript, Vite 6, Tailwind 4, Zustand, Axios |
| python_backend | FastAPI, Prisma Python, PostgreSQL, единый Gemini REST-клиент |
| room-finder-java | Java-мост HTTP → TCP для поиска свободного кабинета |
| mock-cpp-room-server | Локальный тестовый TCP-ответчик; не реальная проверка камер |
| camera-service | Отдельный C++ каркас, созданный до ограничения работ Python-бэкендом; не интегрирован и не проверен с оборудованием |

Расписание привязано к группе студента. Новые задачи, заметки, карточки, викторины и диалоги принадлежат пользователю и сохраняются в PostgreSQL. Статистика собирается из данных, а не из демонстрационных массивов. Только публичная главная содержит явно подписанные примеры.

Дизайн: [Warm Glass](../design-system/aituto/MASTER.md). Запуск и контракты Python: [README](../python_backend/README.md).

Проверено: сборка frontend, 19 Python-тестов с временными данными PostgreSQL, живой Gemini-текст, карточки и структурированная викторина. Живая проверка 8 октября 2026: викторина из 3 вопросов включает multiple_choice, true_false, short_answer и проходит Pydantic. Возможны временные HTTP 503 от провайдера; приложение обрабатывает их как ошибку, без сохранения неполного материала.

Единственный backend приложения — `python_backend`. Старый каталог Node/Fastify удалён. Оба Docker Compose собирают Python-образ и сохраняют имя сервиса `backend` для адресации через nginx/Vite. Схема PostgreSQL и том `postgres-data` сохранены. Скрипт заполнения базы перенесён в `python_backend/scripts/seed.py`; запускается вручную. Загрузки хранятся в `python_backend/uploads`, которая подключается к контейнеру.

Проверка удаления Node-бэкенда, 9 октября 2026: все 82 API-маршрута сохранены; 21 тест прошёл локально и в Python Docker-образе с отдельной PostgreSQL. Проверены повторное заполнение демоданных без дубликатов и смены существующих паролей, сборка frontend, вход и API через Vite и production nginx, загрузка и скачивание файлов. Старые контейнеры приложения пересозданы с новой конфигурацией без запуска; текущий сайт продолжает работать через локальные Python/Vite. Контейнер PostgreSQL и его том сохранены.

Не проверено: реальный C++ поиск/камеры, production-развёртывание на внешнем сервере, достоверный screenshot-review из-за устаревших снимков в инструменте управления браузером.
