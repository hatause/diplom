# Текущее устройство Aituto

Актуализировано 15 октября 2026 года. Подробное руководство: [README](../README.md). Основа диплома: [diplom.md](../diplom.md).

| Часть | Реализация и границы |
|---|---|
| Основной интерфейс | React 19, TypeScript, Vite 6, Tailwind 4, Zustand, Axios |
| Основной API | Единственный backend приложения: Python/FastAPI, Pydantic, Prisma Python |
| Хранение | PostgreSQL 16; вложения в `python_backend/uploads` |
| ИИ | Общий Gemini REST-клиент на httpx, структурированные ответы и обработка ошибок |
| Практикум ПК | React-оболочка → HTML/JS iframe → отдельный Three.js/WebGL iframe; SVG при отсутствии WebGL |
| Поиск кабинета | Python → Java HTTP-мост → внешний C++ TCP-движок |
| Заглушки | `mock-cpp-room-server`, `mock-schedule-server`: локальные тестовые ответы |
| Камеры | `camera-service` — самостоятельный C++ каркас; не интегрирован в рабочий сайт и не проверен с оборудованием |
| Production | Azure VM, Docker Compose, PostgreSQL/backend/frontend/Nginx, HTTPS сайта `sizizxc.me` |

Старый Node/Fastify backend удалён. Node используется для инструментов frontend и Prisma CLI. Название рабочей папки `AItutorJavaServer` не определяет язык основного сервера. Java/C++ — дополнительная интеграция, а не весь backend.

Расписание связано с группой студента. Материалы и операции ограничиваются ролью и правами доступа. Задачи, заметки, карточки, викторины и диалоги принадлежат пользователю. Companion хранит типизированные JSON-записи в `AIInteraction`, активность — в `StudySession`. Практикум использует отдельную модель `PcLabProgress` с ревизиями. Статистика приложения формируется из сохранённых данных; демонстрационные примеры главной подписаны.

Схема находится в `python_backend/schema.prisma`. Приложение не изменяет её и не заполняет базу при запуске. Seed вызывается вручную; `--demo` добавляет учебные аккаунты, сохраняя существующие пароли. Compose сохраняет имя проекта `aitutor` и том `postgres-data`. Перед обновлениями отдельно сохраняются БД, вложения и серверная конфигурация.

Палитра сайта и обоих документов практикума объединена в `frontend/public/pc-lab-assets/site-theme.css`. Светлая тема кремовая с коричневыми акцентами, тёмная — тёплая коричневая. Смена оформления не перезапускает упражнение. Дизайн-система: [Warm Glass](../design-system/aituto/MASTER.md).
