# Повторный аудит — 15 октября 2026

## Исправления

- Расписание: отменяются запросы предыдущего режима «Сегодня/Неделя», чтобы поздний ответ не подменял текущий список.
- Аналитика: ошибка начальной загрузки показывает сообщение и повторную попытку вместо пустой страницы. Даты результатов и активности рассчитываются в часовом поясе школы.
- Генерация теста: параметры блокируются на время запроса, чтобы созданный тест не оказался связан с изменёнными настройками.
- Лекции: загрузка, объяснение, извлечение текста и генерация теста отменяются при смене страницы; старый ответ не переносится в другую лекцию.
- Проверка ответов: варианты выбора сохраняют значимость регистра и пунктуации (например, Co/CO); порядок нескольких выбранных вариантов не влияет на результат. Свободный текст сохраняет прежнюю нормализацию. Учтено числовое представление строковых JSON-ответов Prisma.
- Достижения: пропущенные вопросы больше не увеличивают счётчик отвеченных вопросов.
- Доступ: смена роли преподавателя на студента прекращает служебный доступ к закрытым материалам, даже если сохранились прежние связи с группой или авторство лекции. Обычный доступ студента к своей группе сохраняется.
- Java: отмена брони ограничена аудиторией, текущим днём и указанным интервалом; остальные записи остаются. Обратный интервал отклоняется. Удаление по ID использует ID записи.
- Java TCP: повреждённый JSON или ответ, не являющийся объектом, приводит к ошибке соединения/протокола вместо ложного результата «свободных кабинетов нет».

## Очистка

Удалены неиспользуемые схемы и сериализаторы прежнего backend, совместимый импорт старого Gemini-клиента, дубликат JSON-helper, незавершённый fix_pyright и ручные отладочные HTTP-скрипты. Удалены старые скрипты, сбрасывавшие пароль существующего администратора; документированный scripts/seed.py сохранён.

Удалены девять прямых frontend-зависимостей без импортов и неиспользуемый Python SDK google-generativeai (рабочий клиент использует httpx). Удалены отслеживаемые сгенерированные JS-конфиг Vite и tsbuildinfo. Сборка отдельно проверяет TypeScript приложения и конфигурации без генерации дублирующего vite.config.js, который раньше мог перекрывать изменения vite.config.ts.

## Проверка

- 65 Python-тестов прошли на отдельной чистой PostgreSQL. Включены новые регрессии смены роли, оценки вариантов, дат аналитики и достижений. Основная БД не использовалась для тестов.
- 9 Java-тестов прошли: TCP-клиент и отмена брони с отдельной H2 в режиме совместимости MSSQL. Физический сервер SQL Server не использовался.
- Frontend lint и production-сборка прошли. npm audit --omit=dev: 0 известных уязвимостей на момент проверки.
- Playwright: 32 открытия страниц студента, преподавателя и администратора с настоящим локальным API и отдельными демоданными; без неожиданных HTTP-ошибок и необработанных ошибок JavaScript.
- Дополнительно проверены сообщение/retry при 503 аналитики, переключение расписания с задержанным ответом и четыре страницы при ширине 320 px (профиль, AI-чат, план, заметки). Итого 38 браузерных проверок.
