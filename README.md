## 🚀 Введение в платформу

AI Tutor решает главную проблему современного онлайн-образования — **отсутствие персонализации**. Обычные тесты статичны, а лекции не подстраиваются под ученика. 

Наш проект использует **Generative AI (Google Gemini)** для:
1. Создания уникальных тестов "на лету", основываясь на слабых темах конкретного студента.
2. Автоматического преобразования текста лекций в проверочные вопросы для преподавателей.
3. Оказания помощи в формате диалога 24/7 (AI Чат-бот).

---

## 🎉 Последние обновления (Миграция на Python и Новые Режимы)

Проект был успешно перенесен со старого Node.js бэкенда на **новый высокопроизводительный бэкенд на Python (FastAPI + Prisma)**. В процессе миграции весь старый функционал был сохранен, а также были добавлены мощные новые фичи:

*   🐍 **Полная миграция на Python**: Бэкенд переписан на FastAPI, что улучшило скорость работы с AI, упростило интеграцию с Google Gemini и сделало архитектуру более современной.
*   👨‍🏫 **Режим Фейнмана (Feynman Mode)**: Новый образовательный режим, где не ИИ учит вас, а *вы учите ИИ*! Вы объясняете концепцию своими словами, а ИИ выступает в роли дотошного ученика, задает вопросы и выявляет пробелы в ваших знаниях.
*   ⚔️ **Режим Дебатов (Debate Mode)**: Выберите тему, выберите позицию (за или против), и ИИ будет аргументированно спорить с вами, развивая ваши навыки критического мышления и аргументации.
*   💬 **Система контактов и поиска**: Встроенный мессенджер получил глобальный поиск по пользователям. Теперь вы можете находить однокурсников или преподавателей по имени и сразу начинать с ними чат.
*   📚 **ИИ с контекстом лекций**: Теперь ИИ Тьютор автоматически "читает" добавленные преподавателем лекции и может объяснять материал, опираясь строго на учебную программу курса.

## 👨‍🎓 Руководство Студента (Учимся с AI)

Как только вы входите на платформу под ролью `STUDENT`, вы попадаете в экосистему умного обучения.

### Регистрация и Дашборд
На вашем Дашборде (Главной панели) отображается ваша текущая статистика:
- **Уровень мастерства (Mastery Level)**: от Beginner (0-30) до Mastered (95-100).
- **Стрик (Streak)**: Количество дней подряд, когда вы учитесь. Это мотивирует заходить каждый день.
- **Опыт (XP)**: Баллы, которые вы получаете за правильные ответы и пройденные тесты.

### Прохождение Умных Тестов
В разделе предметов вы можете запустить **Генерацию Теста**. 
**Как это работает "под капотом":**
Когда вы нажимаете "Пройти тест", ИИ анализирует вашу предыдущую историю:
1. Он находит темы, где ваш `Mastery Score` ниже 60%.
2. Он находит ваши последние ошибки в прошлых тестах.
3. Он собирает эту информацию и просит AI сгенерировать тест, который **усиленно проверяет именно ваши слабые места**, избегая повторения старых вопросов.

Типы вопросов:
- `single_choice` (Один правильный ответ)
- `multiple_choice` (Несколько вариантов)
- `true_false` (Правда/Ложь)

За каждый правильный ответ начисляется **5 XP**, за идеальное прохождение теста — **бонус 50 XP**.

### Общение с AI-Тьютором
Если вы не поняли, почему ошиблись в тесте, или вам нужно объяснить сложную концепцию из лекции, вы можете открыть **AI Чат**. 
Тьютор "знает" контекст предмета и общается с вами как терпеливый учитель. Он не дает прямых ответов на контрольные, а задает наводящие вопросы (метод Сократа), чтобы вы сами пришли к решению.

### Геймификация: Опыт, Уровни и Стрики
Обучение должно быть веселым. Система начисляет опыт по правилам:
- `TEST_COMPLETED`: 10 XP
- `CORRECT_ANSWER`: 5 XP
- `PERFECT_SCORE`: 50 XP
- `STREAK_BONUS`: 20 XP

Выполняя задания ежедневно, вы повышаете свой стрик и зарабатываете уникальные "Достижения" (Achievements).

## 👨‍🏫 Руководство Преподавателя

Преподавательская панель (`TEACHER`) призвана сэкономить сотни часов рутинной работы.

### Создание Курсов и Лекций
Вы можете создавать предметы (Subjects), разбивать их на темы (Topics) и загружать текстовые лекции (Lectures). Платформа поддерживает форматирование текста (Markdown).

### Генерация Тестов в 1 Клик (Магия AI)
Самая мощная функция для преподавателя.
Вместо того чтобы вручную придумывать десятки вопросов, вы просто:
1. Открываете свою лекцию.
2. Нажимаете **"Сгенерировать тест по лекции"**.
3. Указываете количество вопросов и сложность.

**Что делает AI?**
Система передает текст вашей лекции в Google Gemini с системным промптом, который требует создать вопросы, **строго опираясь на материал лекции**. AI автоматически генерирует вопросы, правильные и неправильные варианты ответов и раскидывает их по типам (один выбор, множественный, правда/ложь). Тест сохраняется в базе и сразу доступен студентам!

### Аналитика Успеваемости Студентов
Преподаватель видит общую статистику: какие темы даются студентам тяжелее всего. Это позволяет корректировать план занятий и объяснять сложные концепции на следующих уроках.

## 🚪 Поиск свободного кабинета

Раньше эта функция работала через Telegram-бота ([team-ENERGO](https://github.com/hatause/team-ENERGO)), теперь она доступна на сайте: страница **«Поиск кабинета»** (`/classroom`).

```
Сайт → Aituto backend (FastAPI) → Java schedule-server (POST /api/bridge) → C++ сервер (TCP) → Java → backend → сайт
```

- Алгоритм не изменён: Java выбирает ближайшую пару (08:00, 09:30, 11:00, 12:40, 14:10, 15:30, по времени Asia/Almaty, допуск 30 минут) и передаёт C++ серверу `{id, start_time, duration, corpus}` (4 байта длины + JSON).
- Сайт обращается только к backend. Адрес Java-сервера, порты и ключи хранятся в env backend.

### API

`GET /api/v1/classroom/locations`: список корпусов.

`POST /api/v1/classroom/search` (нужен JWT):

```json
{ "locationId": "corp_a", "durationMinutes": 80 }
```

| Ситуация | HTTP | Ответ |
|---|---|---|
| Найден | 200 | `{"success": true, "classroom": "А-301", "additionalData": {...}}` |
| Не найден | 200 | `{"success": false, "reason": "not_found", "message": "..."}` |
| Неверный запрос | 400 | `reason: "invalid_request"` |
| Java недоступна | 503 | `reason: "service_unavailable"` |
| C++ недоступен | 503 | `reason: "search_engine_unavailable"` |
| Таймаут | 504 | `reason: "timeout"` |
| Перегрузка | 503 | `reason: "busy"` |

### Запуск локально

Java-сервер из team-ENERGO лежит в `room-finder-java/` (алгоритм не изменён, пароли и адреса вынесены в env).

```bash
# 1. Java bridge + C++ (если CPP_SERVER_HOST не задан, запускается локальная заглушка C++)
./scripts/start-room-finder.sh                       # Java на 127.0.0.1:3333
# с настоящим C++ сервером:
CPP_SERVER_HOST=<ip> CPP_SERVER_PORT=2222 ./scripts/start-room-finder.sh

# 2. backend (в .env: ROOM_FINDER_JAVA_URL=http://127.0.0.1:3333) и frontend как обычно
cd python_backend && python run.py
cd frontend && npm run dev
```

Переменные Java-сервера: `SERVER_PORT`, `SERVER_ADDRESS` (по умолчанию `127.0.0.1`), `CPP_SERVER_HOST`, `CPP_SERVER_PORT`, `DB_URL`, `DB_USERNAME`, `DB_PASSWORD` (MS SQL нужен только для загрузки расписания и отмены брони, для поиска не нужен).

## 🧠 Как работает AI: Техническая Архитектура

Проект построен как монорепозиторий и разделен на две основные части: **Frontend** (React + Vite) и **Backend** (Node.js + Fastify).

### Сервис Генерации Тестов (`test-generation.service.ts`)
Это сердце платформы. Когда поступает запрос на генерацию теста, сервис выполняет следующие шаги:
1. **Сбор контекста обучения (Learning Context)**:
   Делается сложный запрос в PostgreSQL (через Prisma ORM) для получения последних попыток (`attempts`) пользователя, вычисления средних баллов и извлечения списка неправильных ответов.
2. **Формирование Промпта**:
   Текст формируется динамически:
   *«Сгенерируй тест из 10 вопросов. Студент слаб в темах: Алгебра, Дроби. В последних тестах он ошибался в "Умножении матриц". Сделай упор на эти темы.»*
3. **Запрос к Gemini API**:
   Используется модель Gemini с требованием вернуть ответ строго в формате JSON.
4. **Валидация (Zod)**:
   Полученный от ИИ JSON прогоняется через схему валидации Zod. Если ИИ ошибся в структуре, система пытается автоматически "починить" JSON (например, добавить недостающие ID), либо просит ИИ переделать задачу.

### Технологический Стек
* **Frontend**: React 19, TailwindCSS v4, Zustand, Radix UI. Интерфейс следует стилю "Liquid Glass" с плавными анимациями (Framer Motion).
* **Backend**: Fastify (очень быстрый веб-фреймворк), Prisma ORM для типобезопасной работы с БД.
* **База данных**: PostgreSQL 16.
* **Деплой**: Docker & Docker Compose.

## ⚙️ Установка и Развертывание (Деплой)

Для локального запуска или деплоя на сервер используется Docker Compose.

### Шаг 1. Клонирование и настройка
```bash
git clone https://github.com/hatause/diplom.git
cd diplom
cp .env.example .env
```
Откройте файл `.env` и впишите туда ваш `GEMINI_API_KEY` (ключ можно получить в Google AI Studio).

### Шаг 2. Запуск контейнеров
```bash
docker-compose up -d --build
```
Это поднимет:
- Базу данных PostgreSQL (порт 5433)
- Backend (порт 4000)
- Frontend (порт 5173)

### Шаг 3. Инициализация Базы Данных
Чтобы создать таблицы и заполнить их тестовыми данными:
```bash
docker exec aitutor-backend npx prisma db push
docker exec aitutor-backend npm run prisma:seed
```
